# Enterprise VCP to AWS Migration Simulation

Simulating an enterprise migration from Versa Controller Platform to AWS using Terraform, automation, observability, and operational runbooks.

## Overview

This project models the planning, infrastructure, execution, validation, and incident-handling lifecycle of a production-style VCP to AWS migration.

## Objectives

- Provision the AWS target environment with Terraform.
- Simulate branch onboarding and migration validation.
- Model migration failures and operational responses.
- Automate infrastructure and health checks.
- Produce enterprise migration documentation and runbooks.

## Scope

- AWS networking and compute infrastructure
- Migration planning and execution workflow
- Branch onboarding simulation
- Validation and rollback procedures
- Monitoring and incident response
- Automation and operational documentation

## Technologies

- AWS

- Python
- GitHub Actions
- CloudWatch
