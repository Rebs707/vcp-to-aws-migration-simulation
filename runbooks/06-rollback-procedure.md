# Rollback Procedure

## Purpose

Restore the previous VCP state after a service-impacting migration change.

## Procedure

1. Confirm the migration introduced the service impact.
2. Stop further onboarding activity.
3. Restore the previous VCP configuration.
4. Validate controller and branch recovery.
5. Record the rollback outcome.
6. Create and distribute the required issue report.

## Classification

- Outcome: `ROLLBACK`
- Issue report: Required
